System Architecture

Core Digital Security Principles

Engineered according to the E-Chunab Master Specification.

🔒 Private Storage

Citizenship front and back documents are uploaded to private Supabase Storage buckets, strictly isolated via signed RLS authorization.

🛡️ Double-Vote Defense

Enforced by PostgreSQL composite unique constraints (voter_id, election_id, position_id) making double-voting mathematically impossible.

🗳️ Secret Ballots

Public results display only aggregate tallies. The voter results interface never reveals individual candidate selections after submission.

👥 Role Integrity

Voter registration strictly forces voter roles. Elevation to admin is performed securely server-side or via administrative database controls.
